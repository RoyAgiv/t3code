# Contributing to RoyAgiv/t3code

For setup, tests, and desktop packaging, see the [development runbook](docs/operations/development.md#first-checkout). Follow [AGENTS.md](AGENTS.md) for work in this fork.

An assigned change can go straight to implementation, verification, and integration. Open an issue or discussion when a decision or a bug report would help. GitHub applies the repository’s configured access and review rules. The `vouch:*` and `size:*` labels describe a pull request.

Keep changes focused, explain their purpose, and include the checks that exercised them. Include visual evidence when it helps show changed behavior. Follow the [documentation guidance](AGENTS.md#documentation) for changes that affect user guides or maintainer procedures.

For a contribution to the upstream project, follow [upstream’s contribution instructions](https://github.com/pingdotgg/t3code/blob/main/CONTRIBUTING.md).
